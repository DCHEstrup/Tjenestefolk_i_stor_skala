# Tjenestefolk_i_stor_skala
Projektet ”Tjenestefolk i stor skala. Landsdækkende database over tjenestefolk på alle danske herregårde”, udføres af databasemedarbejder, cand.mag. Andreas Emil Mikkelsen ved Dansk Center for Herregårdsforskning og udføres i løbet af 2025-2027 med støtte fra Augustinus Fonden.
Projektet udvikler en tematiseret database over tjenestefolk ved alle de mere end 700 danske herregårde over en periode på over hundrede år. Projektet vil sikre, tilgængeliggøre og formidle den særlige kulturarv, der gemmer sig i de danske folketællingers enestående og detaljerede optegnelser over de danske husstande i fortiden og systematisk aktivere og udvikle dette materiale. 
Databasen vil give mulighed for at tegne et reelt og repræsentativt billede af husholdningernes opbygning og forskelligheder, spore variationer i herregårdshusholdets sammensætning over tid og i et geografisk og socialt perspektiv samt skabe indsigt i, hvordan den samfundsmæssige udvikling påvirkede herregårdenes hushold og tjenestefolk
Materiale fra databasen vil med tiden blive stillet til rådighed for offentligheden via formidlingsplatformen www.danskeherregaarde.dk og anvendes bredt i forskningscenterets og dets samarbejdspartneres formidlingsarbejde. 
Databasen udvikles desuden som forskningsinfrastruktur for forskningscenterets øvrige forskning i praktiske og ideologiske rammer om tjenesteforholdet og herregården som husstand og indgår i løbende samarbejde med disse projekter.
